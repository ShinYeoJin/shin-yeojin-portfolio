## 🛠 기술 스택

- **Framework**: Next.js 14 (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Deployment**: Vercel

## 📁 프로젝트 소개

### GeoMonitor 계측 모니터링 시스템
- 실제 건설 현장(유현건설)에서 운영 중인 실무 프로젝트
- 지반 계측 센서 데이터를 실시간으로 수집·저장·시각화
- **기술 스택**: Next.js, TypeScript, Node.js, Express.js, PostgreSQL, AWS RDS, 카카오맵 API, Vercel, Render
- **배포**: [바로가기](https://yuhyun-sensor-monitoring-front.vercel.app)
- **GitHub**: [바로가기](https://github.com/ShinYeoJin/yuhyun-sensor-monitoring-front)

### BLUM Landing Page
- 오스트리아 프리미엄 가구 피팅 브랜드 blum의 랜딩 페이지
- 동일한 브랜드를 3가지 디자인 컨셉으로 구현한 멀티 버전 프로젝트
- **기술 스택**: Next.js, TypeScript, Tailwind CSS, Vercel
- **배포**: [바로가기](https://blum-landing.vercel.app/v1)
- **GitHub**: [바로가기](https://github.com/ShinYeoJin/blum-landing)

### J-Line 속눈썹 펌 홈페이지
- 실제 네이버에 등록되어 운영 중인 미용 홈페이지
- **기술 스택**: Next.js, TypeScript, Tailwind CSS, Vercel

## 🚀 로컬 실행 방법

```bash
# 패키지 설치
npm install

# 개발 서버 실행
npm run dev
```

개발 서버 실행 후 [http://localhost:3000](http://localhost:3000) 접속
